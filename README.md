### What I learned

- used an article element instead of using a simple div tag:

  ```html
  <article>Some HTML code I'm proud of</article>
  ```

- Used google fonts on the body:
  ```css
  body {
    font-family: "Inter", sanserif;
  }
  ```
- Added hover state to the anchor element of the list items:
  ```css
  ul a:hover {
    background-color: var(--green);
    color: var(--grey-900);
  }
  ```
- Used flexbox to center the article.
